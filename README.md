# 雨课堂自动答题助手 (Yuketang Auto Answer)

一个基于浏览器自动化的雨课堂课程监控与自动答题工具。自动检测正在上课的课程，实时捕获课堂习题，并在限时内自动完成作答。

## 功能特性

- 🔍 **自动课程检测**：定时扫描"我听的课"列表，自动识别正在直播/上课的课程
- ⚡ **实时题目监控**：进入课堂后高频刷新，第一时间捕获老师发出的习题
- 🤖 **智能自动答题**：自动读取题目内容，根据知识库/AI模型选择答案并提交
- ⏱️ **限时优化**：针对30秒答题窗口优化流程，确保快速响应
- 📝 **多题型支持**：支持单选题、多选题、判断题，预留填空题扩展接口

## 技术栈

- **Python 3.8+**
- **Playwright** - 浏览器自动化控制
- **Pydantic** - 配置管理
- **Loguru** - 日志记录
- **OpenAI API** (可选) - AI辅助答题

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 安装浏览器驱动

```bash
playwright install chromium
```

### 3. 配置

复制 `config.example.yaml` 为 `config.yaml`，根据你的需求修改配置：

```bash
cp config.example.yaml config.yaml
```

主要配置项：
- `check_interval`: 课程列表扫描间隔（秒）
- `monitor_interval`: 课堂内题目监控间隔（秒）
- `course_keywords`: 监控的课程关键词列表
- `answer_strategy`: 答题策略 (local / ai)

### 4. 登录

首次运行需要扫码登录雨课堂：

```bash
python main.py --login
```

使用微信或雨课堂APP扫描二维码完成登录，登录状态会自动保存。

### 5. 启动监控

```bash
python main.py
```

## 工作原理

```
┌─────────────┐
│  定时扫描    │  每 N 秒检查课程列表
│  课程列表    │
└──────┬──────┘
       │ 发现正在上课的课程
       ▼
┌─────────────┐
│  进入课堂    │  点击进入直播课堂页面
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  高频监控    │  每 M 秒刷新检查题目
│  题目弹出    │
└──────┬──────┘
       │ 检测到题目
       ▼
┌─────────────┐
│  读取题目    │  提取题干、选项
│  分析作答    │  根据知识库/AI选择答案
│  提交答案    │  点击提交按钮
└─────────────┘
```

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `check_interval` | 课程列表扫描间隔（秒） | 300 |
| `monitor_interval` | 课堂内题目监控间隔（秒） | 10 |
| `monitor_duration` | 单门课程监控时长（分钟） | 50 |
| `course_keywords` | 监控的课程关键词（空则监控全部） | [] |
| `answer_strategy` | 答题策略：local(本地规则) / ai(AI辅助) | local |
| `headless` | 是否无头模式运行 | false |

## 答题策略

### 本地模式 (local)
- 基于内置药学/化学知识库进行规则匹配
- 适用于常见基础题目
- 无需联网，响应速度最快

### AI模式 (ai)
- 调用大语言模型进行题目分析和答案选择
- 准确率更高，支持复杂题目
- 需要配置 OpenAI API Key
